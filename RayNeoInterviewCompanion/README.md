# RayPrompt

A hands-free AI assistant and adaptive teleprompter for smart glasses.

Native SwiftUI assistance for conversations, coding, presentations, and hands-free guidance, with RayNeo iO BLE, continuous speech recognition, Apple Foundation Models, optional Gemini Flash, adaptive reading, automatic contextual handoff, Code Tutor, personal memory, and a VS Code companion.

See the [project README](../README.md) for features, architecture, requirements, privacy, development commands, and limitations.

Open `RayNeoInterviewCompanion.xcodeproj` using its shared `RayNeoInterviewCompanion` scheme. The public display name is **RayPrompt**. Internal module, target, bundle, Keychain, and Bluetooth identities retain their existing names for installation compatibility.
